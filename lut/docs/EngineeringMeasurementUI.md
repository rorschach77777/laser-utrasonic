# 数据采集页面分层

默认工程页以运行状态、采集操作、测量记录、当前厚度、动态检出率、SNR、管长、厚度统计和轴向剖面为核心。深色看板参考生产监测屏布局，窄窗口将统计与曲线上下排列。

“实验”按钮打开保留的完整采集页面，首次点击才加载，关闭后保留其控件状态。以下项目从工程主页面移入实验窗口：

- 设备选择、配置文件、触发源/边沿/电平、延迟和采集设置。
- 带通滤波、纵轴范围、原始波形显示、波形刷新间隔。
- 标准厚度、容差、结构长度、最小宽度、回波模式及核心测厚参数。
- 实时原始/滤波波形、按帧厚度历史、诊断状态与检出率重置。
- 雷达至激光距离、轴向CSV设置和逐帧波形保存。

工程页无参数输入，启停与记录操作仍调用现有后端。实验设置作用于同一后端，不创建第二个采集实例。工程页不创建波形绘图对象；关闭实验窗口后停止向其波形图提交波形与标记。后端原有波形信号生成尚未裁剪。

管长、平均/最小/最大厚度沿用现有控制器统计口径；不是新增的质量判定或温度换算。雷达/管件状态仍是现有推定值。未接入批次号、冷热态换算、偏心度、周向多通道和公差上下限数据，因此未仿制参考图中这些图表，也不生成假数据。

错误通过工程页提示框显示。轴向曲线复用场景图绘制组件，100 Hz测量与约10 Hz绘制更新保持原设计。完整应用运行需要 Qt 6.5+ 与现有 Windows/DAQ 依赖，须在目标机器验证真实采集、停启、记录、回填、弹窗切换和长时间运行。
