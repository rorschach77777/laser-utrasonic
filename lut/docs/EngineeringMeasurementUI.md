# 工程测厚界面

工程页面按生产监测屏的格局组织：顶部运行状态与操作条，左侧管件统计、测量质量，右侧壁厚趋势、轴向壁厚剖面。统一使用深灰底、橙色导航标识、蓝色测厚结果和绿色运行状态。进入数据页时，应用顶栏与侧栏切换为配套深色样式；其他页面保留原有浅色主题。

## 页面布局

- 顶部：待机 / 测量 / 暂停状态、时间、开始 / 暂停 / 继续 / 停止、测量记录、状态详情和实验入口。
- 左上：当前壁厚、最小 / 平均 / 最大厚度、雷达估计管长、运动状态和瞬时速度。
- 左下：动态检出率、当前 SNR、当前结果有效性、管头厚度确认和记录状态。检出率不作为合格率。
- 右上：最近 1000 次厚度结果和该窗口的均值。横轴是测量序号，不把采集帧数当作校准后的时间或管件编号。无效结果留断线，不填零，不连过空洞；孤立有效点可见。T2 历史回填修改对应结果，新采集时重置。
- 右下：复用原有场景图组件绘制轴向剖面，蓝色实测、橙色管尾位置估计、灰色缺口插值。没有有效轴向数据时显示等待状态。

1280×800 下使用左右约 30:70 的四区布局。数据页宽度小于 980 px 时按统计、趋势、质量、轴向剖面顺序改为单列滚动，操作条始终可见。统计值与曲线边界均来自现有控制器；缺少数据时显示占位，不生成演示数据。

工程页已从页面结构移除采集、触发、滤波及算法参数输入，以及原始 / 滤波信号波形显示。生产页的壁厚趋势是测量结果图，不是采集信号波形。

## 实验入口

“实验”按钮打开独立的完整实验页面，包含设备与配置文件、采集 / 触发配置、滤波与波形坐标设置、回波模式 / 核心测厚参数、实时信号波形、原有厚度历史、雷达至激光距离、轴向 CSV 设置和逐帧波形保存。首次进入后保留控件状态，关闭后停止向实验波形图提交波形和标记。实验页面显式使用浅色主题，避免与其原有文字配色冲突。

两个页面共享同一控制器。测厚算法、采集、回填及记录链路沿用现有实现；后端原有波形信号生成没有在此次 UI 设计中裁剪。实验配置影响同一采集流程，不启动第二个实例。

## 数据含义与验证范围

管长、平均 / 最小 / 最大厚度沿用现有统计口径；雷达与管件状态仍是推定值。当前未接入批次 / 材质元数据、冷热态换算、偏心度和周向多通道数据，也未接入工程公差配方，所以没有制作相应图表、合格率或公差报警线。原始诊断状态收进“状态详情”，采集错误继续弹窗提示。

新增结果趋势使用有界 1000 点缓冲，绘图和范围计算最多每 100 ms 一次；轴向剖面继续复用原有约 10 Hz 场景图刷新。没有在产品代码中放入模拟数据。

离屏验证覆盖 1280×800、1024×768、800×800、1600×900 布局，启停 / 暂停 / 继续 / 记录按钮、趋势容量限制、无效结果、历史回填和显示重置。验证使用模拟控制器及自定义绘图类型替身；实际 Qt 6.5+ Windows / DAQ 设备采集和轴向渲染仍须在目标机器验证。
